### 12.2. Spesifikasi Skema 6 Tabel Basis Data SQL

#### 1. Tabel `institution` (Profil Lembaga & KOP)
Menyimpan identitas resmi, legalitas, pimpinan, dan pengaturan KOP surat lembaga.
- `id` INTEGER PRIMARY KEY CHECK (id = 1)
- `name` TEXT NOT NULL: Nama satuan TPQ (`TPQ MUSLIMAT NU AL-IKHLAS`)
- `foundation` TEXT NOT NULL: Yayasan pengampu (`YAYASAN AL FATAH`)
- `headmaster` TEXT NOT NULL: Kepala TPQ (`Ustadzah Hj. Siti Aminah, S.Pd.I`)
- `headmaster_nip`, `headmaster_title`, `headmaster_phone`, `headmaster_education`, `headmaster_syahadah`, `headmaster_period`
- `head_foundation`, `committee_head`, `secretary`, `treasurer`
- `nsq`: Nomor Statistik TPQ Kemenag (`411235150089`)
- `ijop`: Nomor SK Izin Operasional (`Kd.13.15/4/PP.00.7/1420/2024`)
- `notary`: SK Notaris Yayasan (`AHU-0014285.AH.01.04.Tahun 2018`)
- `affiliation`, `method`, `address`, `village`, `subdistrict`, `city`, `province`, `post_code`, `phone`, `email`
- `active_year`, `legal_city`, `target_accreditation`
- `logo_left`, `logo_right`, `logo_left_type`, `logo_right_type`, `logo_left_preset`, `logo_right_preset`
- `kop_logo_layout`: Pilihan tata letak logo (`both` | `left` | `right` | `none`)
- `kop_border_type`: Bingkai garis pemisah KOP (`double-emerald` | `double-black` | `triple-gold` | `solid-green`)
- `signature_headmaster`: Data URL tanda tangan digital Kepala TPQ
- `stamp_image`: Data URL cap stempel resmi lembaga
- `updated_at`: Waktu perubahan data terakhir

#### 2. Tabel `santri` (Buku Induk Peserta Didik)
Menyimpan 25 data peserta didik standar EMIS Kemenag.
- `id` TEXT PRIMARY KEY (e.g. `STR-001` s.d. `STR-025`)
- `nis` TEXT NOT NULL: Nomor Induk Santri (e.g. `2026/001`)
- `nik` TEXT: Nomor Induk Kependudukan 16 digit
- `name` TEXT NOT NULL: Nama lengkap santri
- `gender` TEXT CHECK (gender IN ('L', 'P'))
- `birth_place`, `birth_date`: Tempat dan tanggal lahir
- `class_level` TEXT NOT NULL: Jilid 1-6 / Al-Qur'an & Tajwid
- `parent_name`: Nama orang tua / wali santri
- `parent_phone`: Nomor telepon wali santri
- `address`: Alamat domisili lengkap santri
- `join_date`: Tanggal masuk pendaftaran
- `status` TEXT DEFAULT 'Aktif': Status santri (Aktif / Lulus / Mutasi)
- `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP

#### 3. Tabel `ustadz` (Buku Induk Dewan Guru & Tenaga Kependidikan)
Menyimpan data 6 pendidik Al-Qur'an bersyahadah sah.
- `id` TEXT PRIMARY KEY (e.g. `UST-001` s.d. `UST-006`)
- `nip` TEXT NOT NULL: Nomor Induk Pendidik (e.g. `TPQ-01.001`)
- `nik` TEXT: NIK KTP pendidik
- `name` TEXT NOT NULL: Nama lengkap beserta gelar
- `gender` TEXT CHECK (gender IN ('L', 'P'))
- `education`: Jenjang & program studi perguruan tinggi (S1 / D3)
- `pesantren`: Riwayat pesantren asal pengajar
- `syahadah_method`: Metode Al-Qur'an (An-Nahdliyah / Qiraati / Yanbu'a)
- `syahadah_number`: Nomor registrasi sertifikat kelayakan mengajar
- `syahadah_year`: Tahun kelulusan syahadah
- `assigned_class`: Amanah mengajar rombel / tugas struktural
- `phone`: Nomor WhatsApp pengajar
- `status` TEXT DEFAULT 'Guru Tetap'
- `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP

#### 4. Tabel `inventaris` (Buku Sarana & Prasarana)
Menyimpan 12 aset fisik sarpras TPQ.
- `id` TEXT PRIMARY KEY (e.g. `INV-001` s.d. `INV-012`)
- `code` TEXT NOT NULL: Kode inventaris barang (e.g. `INV/TPQ/MEJ/001-030`)
- `name` TEXT NOT NULL: Nama barang & spesifikasi teknis
- `category` TEXT NOT NULL: Perabot Belajar / Media Ajar / Elektronik / Sanitasi
- `qty` INTEGER NOT NULL: Volume / jumlah barang
- `unit` TEXT DEFAULT 'Unit': Satuan (Unit, Roll, Set, Buah, Titik)
- `condition` TEXT DEFAULT 'Baik': Kondisi fisik (Baik / Rusak Ringan)
- `source`: Sumber pengadaan (Yayasan / Wakaf Wali / Kas TPQ)
- `location`: Lokasi penempatan aset di lingkungan TPQ
- `acq_year`: Tahun perolehan barang
- `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP

#### 5. Tabel `kas` (Buku Kas Umum / BKU Operasional)
Menyimpan 8 transaksi arus kas masuk dan keluar.
- `id` TEXT PRIMARY KEY (e.g. `KAS-001` s.d. `KAS-008`)
- `date` TEXT NOT NULL: Tanggal transaksi (YYYY-MM-DD)
- `type` TEXT CHECK (type IN ('in', 'out')): Jenis arus dana
- `category` TEXT NOT NULL: Infaq SPP / Donatur / ATK / Honor Guru / Operasional
- `amount` INTEGER NOT NULL: Nominal uang dalam Rupiah
- `proof_number`: Nomor bukti kuitansi (`KW-...`) atau nota (`NT-...`)
- `description`: Uraian lengkap transaksi
- `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP

#### 6. Tabel `checklist_status` (Status Fisik Bukti Akreditasi)
Menyimpan progres verifikasi 8 standar instrumen akreditasi.
- `item_id` TEXT PRIMARY KEY: Kode dokumen akreditasi
- `status` TEXT CHECK (status IN ('ready', 'progress', 'missing')): Status kelengkapan fisik
- `notes`: Catatan asesor atau rekomendasi penyiapan dokumen
- `updated_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP

### 12.4. Alur Kerja Dual Persistence (Zero Data Loss)

```
[ Antarmuka Web (UI Browser) ]
              │
              ├── 1. Perubahan Data (Tambah/Ubah/Hapus)
              ▼
   [ LocalStorage Cache ]  <--- Failover cepat di peramban
              │
              ├── 2. Background Asynchronous REST API Call
              ▼
    [ Python server.py ]
              │
              ├── 3. SQL Transaction (BEGIN / COMMIT)
              ▼
[ SQLite 3 (database/tpq_alikhlas.db) ]  <--- Penyimpanan Permanen di Disk Komputer
              │
              ├── 4. Real-time Auto SQL Export Dump
              ▼
[ SQL Dump Script (database/tpq_alikhlas.sql) ] <--- Siap Impor ke MySQL / Hosting
```

## 13. PANDUAN PEMELIHARAAN SISTEM, BACKUP & PEMULIHAN BENCANA

### 13.1. Cara Menjalankan Server Lokal di Windows
Buka PowerShell atau Command Prompt pada direktori kerja, lalu jalankan:
```powershell
python server.py 8080
```
Server akan menyajikan portal di tautan: `http://localhost:8080/`.

### 13.2. Cara Mengambil Cadangan (Backup)
1. **Melalui Antarmuka Web**:
   - Klik tombol **Database & Backup** di header navigasi kanan atas.
   - Pilih **Unduh Script SQL (.sql)** untuk mendapatkan dump SQL universal.
   - Atau pilih **Unduh File SQLite (.db)** untuk mendapatkan basis data biner langsung.
2. **Secara Manual di File Explorer**:
   - Salin file `database/tpq_alikhlas.db` atau `database/tpq_alikhlas.sql` ke flashdisk, Google Drive, atau media penyimpanan eksternal lainnya.

### 13.3. Cara Memulihkan Data (Restore)
1. **Memulihkan ke Server SQLite Lokal**:
   - Cukup letakkan file cadangan `tpq_alikhlas.db` ke dalam folder `database/`.
   - Atau jalankan `python database/init_db.py` untuk mengembalikan data awal bawaan resmi.
2. **Mengimpor ke MySQL / MariaDB (phpMyAdmin / CPanel)**:
   - Buat basis data baru, misalnya `tpq_alikhlas`.
   - Buka menu **Import** pada phpMyAdmin.
   - Pilih file `database/tpq_alikhlas.sql`, lalu klik tombol **Import / Kirim**. Seluruh tabel dan data akan tercipta secara instan.
3. **Menggunakan GUI Database Manager (DBeaver / DB Browser for SQLite)**:
   - Buka aplikasi **DB Browser for SQLite**.
   - Pilih **Open Database** -> arahkan ke file `C:\Users\Komputer Vintage\Music\TPQ\database\tpq_alikhlas.db`.
   - Anda dapat melihat, mencari, atau mengedit data secara visual menggunakan antarmuka grafis.
