### 🖨️ CARA MENCETAK (PRINTING INSTRUCTIONS)

1. **Buka file HTML** di browser Google Chrome, Microsoft Edge, atau Mozilla Firefox.
2. Tekan tombol **`Ctrl + P`** (atau klik tombol kuning *"Cetak"* di bagian atas halaman).
3. Pada jendela pengaturan printer browser:
   - **Destination / Printer**: Pilih printer fisik Anda atau pilih *"Save as PDF"* jika ingin disimpan terlebih dahulu.
   - **Pages**: *All* (Semua).
   - **Layout**: 
     - Untuk Box 1, 2, 4, 5, 6 dan Cover: Pilih **Portrait**.
     - Khusus file `03_ODNER_3_...`: Pilih **Landscape** (karena tabel Buku Induk memiliki 12 kolom lebar).
   - **Paper Size**: **A4**.
   - **Margins**: **Default** atau **Minimum**.
   - **Options**: Centang **"Background graphics"** (Grafis Latar Belakang) agar kop warna dan bingkai tercetak sempurna.
4. Klik **Print**.

### 🗂️ SPESIFIKASI PERLENGKAPAN ODNER BANTEX

- **Tipe Map**: Bantex Lever Arch File (Map Odner Bertulang Tebal) ukuran A4, ketebalan punggung 7 cm atau 7.5 cm (Total 6 Box Odner).
- **Label Punggung**: Potong lembar label dari file `00_COVER_DAN_LABEL_PUNGGUNG_ODNER_1_SD_6.html` dan selipkan pada mika bening di punggung map Odner.
- **Cover Depan**: Selipkan lembar cover depan pada kantong depan map (atau tempelkan jika map tanpa kantong).
- **Pembatas Bab**: Gunakan kertas pembatas warna (divider/separator tabs) di setiap sub-nomor dokumen agar asesor mudah membuka halaman yang dituju.
- **Sampel Fisik**: Letakkan bukti nyata di samping map (Buku Jilid An-Nahdliyah/Yanbu'a, Piagam IJOP Asli, Buku Rapor Asli).
